# Océan Fresh — site vitrine

Site statique en français : HTML, CSS et JavaScript.

## Prévisualiser
Décompressez le ZIP puis ouvrez `index.html` dans un navigateur. Internet est nécessaire pour l’image de couverture et les polices externes.

## Publication gratuite avec GitHub Pages
1. Connectez-vous à https://github.com ou créez un compte.
2. Cliquez sur **New repository**, nommez-le `ocean-fresh-site`, choisissez **Public**, puis créez-le.
3. Dans le dépôt, cliquez **Add file → Upload files**.
4. Décompressez le ZIP sur votre appareil puis téléversez les quatre fichiers (`index.html`, `style.css`, `script.js`, `README.md`) à la racine du dépôt.
5. Cliquez **Commit changes**.
6. Allez dans **Settings → Pages**.
7. Sous **Build and deployment**, choisissez **Deploy from a branch** ; sélectionnez `main` et `/(root)`, puis **Save**.
8. Attendez quelques minutes. L’adresse publiée apparaîtra dans la section Pages.

## À vérifier avant présentation
- La fiche indique l’activité sous une formulation qui semble tronquée (« transformation et conservât »). Le site utilise « transformation et conservation » comme normalisation probable : confirmez-la avec votre groupe.
- Vérifiez l’adresse, l’IF et le capital avant publication officielle.
- Les descriptions des services sont des résumés généraux des fonctions mentionnées dans le dossier.
- Aucun produit précis, téléphone, certification ou réseau social n’a été ajouté sans source confirmée.
- Le site est une maquette vitrine statique : pas de paiement, base de données ou formulaire stockant les messages. Le bouton e-mail ouvre le logiciel de messagerie.
